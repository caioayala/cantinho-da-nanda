# um cantinho só seu

Página estática feita para a minha prima: um cantinho com música de Life is Strange, pausa pro chá com exercício de respiração, vídeo de gatinhos, estante de One Direction, frases e um abraço sob demanda.

## Stack

- HTML, CSS e JavaScript puros, num único `index.html`
- Sem build, sem dependências
- Embeds: Spotify e YouTube

## Rodar localmente

Abra o `index.html` no navegador, ou sirva a pasta:

```bash
python3 -m http.server 8000
```

## Deploy

Hospedado na Vercel como site estático (sem framework, sem build command).
